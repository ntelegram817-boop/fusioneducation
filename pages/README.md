## 🎨 Page Template Standard
Each HTML page includes:
- Semantic HTML5 layout with high SEO standards (`<title>`, meta tags, OpenGraph tags).
- Standardized navbar with active page indicators and call-to-action buttons.
- Shared CSS linkages: `assets/css/style.css` alongside page-specific sheets (e.g. `admission.css`, `dashboard.css`).
- Floating WhatsApp chat and scroll-to-top buttons.
- Standardized footer with branch addresses, quick links, and social connections.
