# Utilities Module (`/utils`)

This directory contains standalone server-side helper modules.

---

## 📁 Utility Modules

### 1. [`emailSender.js`](file:///w:/Antigravity/website-2.o.2/utils/emailSender.js)
- Provides email transmission helpers via Nodemailer / SMTP configurations.
- Handles automated dispatch of admission confirmation notifications, student welcome messages, and password recovery emails.

### 2. [`passwordGenerator.js`](file:///w:/Antigravity/website-2.o.2/utils/passwordGenerator.js)
- Helper utility to generate secure temporary passwords, random alphanumeric registration tokens, and verification codes.
